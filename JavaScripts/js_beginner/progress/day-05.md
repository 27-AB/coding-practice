# Day Challenge: ASTU Project Insights

## Objective
Analyze university research projects using JavaScript array methods.

## Concepts Practiced
- `filter()` — select projects matching a condition
- `reduce()` — calculate total project funding
- `some()` — check whether at least one project matches
- `map()` — transform project data
- `every()` — verify a condition across all projects

## Learning Goal
Understand how JavaScript array methods can work together to answer real-world questions about university projects.

## Reflection
I practiced selecting projects, calculating funding, checking conditions, and transforming data into useful summaries.

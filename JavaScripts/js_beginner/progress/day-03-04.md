## 1. What I Learned Today

### Array Methods

- **`filter()`** — selects all elements that satisfy a condition and returns a new array.
- **`map()`** — transforms each element and returns a new array.
- **`find()`** — returns the first element that satisfies a condition, or `undefined` if no element matches.
- **`.length`** — gets the number of elements in an array.

### Combining Array Methods

I practiced chaining `filter()` and `map()` to select specific objects and extract their properties.

Example:

```js
const result = tasks
    .filter(task => task.completed === false &&
                    task.priority === "high")
    .map(task => task.title);
```

This selects incomplete, high-priority tasks and returns only their titles.

### Functions and Return Values

- A function can return an array, an object, a number, or another value.
- A function without an explicit return value returns `undefined`.
- I practiced calling one function inside another and using its returned result.

### Objects

I practiced creating objects with named properties and returning a summary object.

```js
const summary = {
    totalTasks: tasks.length,
    completedTasks: countCompletedTasks(tasks),
    incompleteTasks: getIncompleteTasks(tasks),
    highPriorityIncompleteTasks:
        getHighPriorityTaskTitles(tasks)

```

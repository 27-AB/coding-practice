## ✅ What I Learned

* `&&` evaluates operands from left to right and stops when it finds a falsy value.
* `||` evaluates operands from left to right and stops when it finds a truthy value.
* Zero (`0`) and an empty string (`""`) are falsy.
* A string containing a space (`" "`) is truthy.
* Parentheses help control the order of evaluation.
* Logical operators can be used to validate user input.
